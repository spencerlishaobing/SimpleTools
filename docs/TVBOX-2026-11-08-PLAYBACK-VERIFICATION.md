# TVBOX 播放修复验收记录

## 全屏复用原有控件

用户要求：完整复用窗口模式下方的设置，不重新设计菜单；全屏时以半透明背景覆盖视频底部，视频不缩小。

2026-11-08 实机使用 playback-120s.mp4 验证：

- 全屏画面铺满，原有控制条半透明覆盖底部。
- 展开“更多”后，音量、倍速、音轨、字幕选择、字幕文件、比例、字幕延迟、大小、颜色、粗体、在线字幕、字幕链接及解析线路显示在视频之上。
- 展开过程中播放进度持续推进，视频尺寸不因设置展开缩小。
- ESC 恢复普通窗口，视频和完整设置恢复原布局。
- 原生视频窗口去掉 WS_CLIPSIBLINGS 裁剪后，透明 WebView 下方的视频可见；单纯降低窗口层级曾导致底色遮挡，已通过实机发现并修正。

此记录验证显示、展开、ESC 与持续播放。并不代表上述每个功能已逐项操作验收，也不代表已发布安装包。前端 26 项回归通过。

## 夸克扫码与播放

实际账号已完成扫码，落盘存在 __pus、__kps 等，但缺少 __puus。使用这些账号 Cookie 调用网盘 member 初始化接口，HTTP 200/code 0 并下发 __puus；保存后《嫁金钗》第一集连续播放超过 20 秒，播放器显示 3840×2160、25 FPS。

代码已加入 account/info 后携带 Cookie 初始化 member 的步骤，只有获得非空 __puus 才报告成功；不再把仅账号 Cookie 的落盘视为完整登录。当前测试构建包含该修复。尚未重新执行从手机扫码到自动初始化的完整新登录流程。

## 全屏实现清理

删除未使用的 Lua 全屏设置菜单、在线字幕独立弹层入口和旧底部占位计算。全屏直接显示同一个 #tv-controls 及 #tv-controls-more，保留半透明覆盖、3 秒无操作隐藏和 ESC 退出。Lua 只保留播放暂停反馈动画。清理后前端 26 项测试通过，Rust 离线构建成功；新测试程序已启动。本次清理后的全屏逐项可视化复验尚未完成。

## 详情页布局调整

封面固定为 178×267，简介位于右侧；窄窗口使用 148×222 并继续左右排列。简介过长时在右侧滚动，播放线路与选集作为独立区域位于整块信息下方。26 项前端回归通过，离线构建成功；实机《疾速追杀》详情已目视确认封面、简介和下方线路/选集的位置。测试程序保留在该详情页，未发布安装包。

## 在线字幕与颜色

对照 Android SearchSubtitleDialog：直接字幕单选加载后关闭，压缩包应进入文件列表。PC 已改独立弹窗，加载时锁定其他选择、成功关闭、失败保留错误、搜索结果按 token 隔离；影片切换后拒绝旧字幕加载。颜色从错误 RRGGBBAA 改为 mpv 支持的六位 RGB。28 项测试通过，含四种颜色原值传递与连续点击仅加载一次。实机确认弹窗出现、视频暂停且没有覆盖弹窗；发现移出原页面后控件样式缺失及自动填充问题，已修正源码。字幕包文件选择仍未实现，本次未验证实际彩色字幕渲染及真实字幕下载成功闭环，不标记完全验收。

## 字幕包选择实现

新增 tvbox_subtitle_prepare 返回字幕候选文件。ZIP 解压枚举字幕而非只取首项；文件名只用于展示，落盘使用程序生成名称，限制单文件 8MB、总解压 64MB、最多 100 个字幕文件。多文件时进入单选列表，可返回搜索结果；单文件直接加载。新增前端回归确认不自动加载首项、选择第二项后只加载该项且不重复下载。两项字幕专项测试及 cargo check --offline 通过。尚未重新构建运行程序验证此新增路径，Assrt API filelist 仍自动取第一个匹配文件，后续须补齐。
